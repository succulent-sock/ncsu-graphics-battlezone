Battlezone program
##################
All code can be found in the battlezone.js file.
Code for at least one Extra Credit opportunity has been described below.
A personal GitHub repository was necessary to share this program in browser via GitHub pages. NCSU has disabled GitHub pages for new Enterprise accounts. 
##########
How to Run
##########
1. Open Program 5 - Battlezone folder.
2. Open the index.html file in a browser tab.
3.	Parts 2 - 5 output should be gradable.
4.	Press '!'.
5.	Part 6 output should be gradable.
6.	Pressing '!' repeatedly will switch between the two displays.
